# Sentiment Analysis

A Jupyter notebook project for natural-language sentiment classification. The notebook walks through loading text data, preprocessing, feature preparation, model training, and evaluation.

## Use

1. Create a Python environment with Jupyter and the data-science/NLP libraries imported by the notebook.
2. Open `sentiment-analysis-NLP-Project.ipynb`.
3. Run the cells from top to bottom, supplying the referenced dataset where required.

The notebook preserves its outputs so the analysis can also be reviewed directly on GitHub.
